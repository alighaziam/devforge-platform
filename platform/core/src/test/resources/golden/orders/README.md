## Run locally

1. Copy .env.example to .env and set a strong DATABASE_PASSWORD.
2. Build the application with mvn clean package.
3. Start the database and application with docker compose up --build.
4. Check http://localhost:8080/actuator/health.

PostgreSQL is private to the Compose network and the application port is bound to localhost.
Generated output is a starting point, not a production deployment.
